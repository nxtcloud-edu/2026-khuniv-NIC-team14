# 뉴스레슨 (News Lesson) — 요구사항

## 1. 타겟
경제 뉴스를 읽지만 어려운 용어나 현상 때문에 기사의 맥락과 의미까지 이해하기 어려운 사용자

## 2. 문제
기사에 등장하는 개념의 뜻은 검색할 수 있지만, 왜 이 기사에서 중요한지, 어떤 영향을 만드는지까지 연결해 이해하기 어렵고, 읽은 내용이 자신의 지식으로 남기 어려움.

## 3. 핵심 솔루션
경제 뉴스 본문을 붙여넣으면 AI가 기사를 이해하는 데 꼭 필요한 학습 포인트를 1~2개, 최대 3개만 선별한다. 각 포인트를 **쉬운 설명 → 기사 속 맥락 → 경제적 영향** 순서로 학습하고, 마지막에는 사용자가 직접 자신의 언어로 기사를 정리한다. 정리 이후에는 선택적으로 이해도 확인 퀴즈를 풀 수 있다.

## 4. AI 역할
- 기사 전체를 단순 요약하지 않고, **학습할 가치가 있는 핵심 개념·현상을 선별**
- 선별한 개념이 기사에서 갖는 의미와 경제적 영향까지 연결해 설명
- 사용자가 직접 정리한 내용을 참고해, 놓친 부분 위주로 확인 퀴즈/피드백 생성

## 5. 사용 흐름
```
경제 뉴스 본문 붙여넣기
   ↓
AI 핵심 포인트 1~3개 선정
   ↓
포인트별 학습: 쉽게 말하면(개념) → 이 기사에서는(맥락) → 그래서 어떤 영향?(경제적 영향)
   ↓
사용자 직접 정리 ("내 말로 정리해보세요")
   ↓
학습 완료 → 기사 + 학습 포인트 + 내 정리 마이페이지 저장
   ↓
[선택] 이해도 확인 퀴즈 (정리 내용 기반 피드백 포함)
```

## 6. 동작 요건 (기능 명세)

1. 사용자가 경제 뉴스 본문을 붙여넣으면(최대 10,000자), 시스템은 AI를 호출해 핵심 학습 포인트를 1~3개 선정한다.
2. 각 포인트는 "쉽게 말하면(개념 설명)", "이 기사에서는(기사 속 맥락)", "그래서 어떤 영향?(경제적 영향)" 3단 구조로 표시된다.
3. 사용자는 포인트를 순서대로 하나씩 넘겨가며 학습한다 (예: 1/2, 2/2 진행 표시).
4. 모든 포인트 학습이 끝나면, 사용자가 기사를 자신의 언어로 정리할 수 있는 입력창이 제공된다.
5. 정리 입력 시, 힌트로 "이런 내용이 들어가면 좋아요" 형태의 키워드 칩(핵심 개념 기반)을 함께 보여준다.
6. 정리를 마치고 "학습 완료"를 누르면, 원문 기사 + 학습 포인트 + 사용자의 정리 내용이 함께 저장된다.
7. 저장된 학습 기록은 마이페이지에서 목록으로 조회할 수 있으며, 각 항목에서 "내 정리 보기"로 상세 내용을 다시 볼 수 있다.
8. 마이페이지는 누적 통계(직접 정리한 뉴스 수, 이해한 핵심 포인트 수, 이번 주 학습 수, 연속 학습일)를 표시한다.
9. [선택 기능] 학습 완료 후, 사용자가 원하면 해당 기사 기반 확인 퀴즈(객관식/OX, 2~3문항)를 풀 수 있다.
10. 퀴즈 문제는 원문 기사와 AI가 선정한 핵심 포인트를 근거로 생성한다.
11. 퀴즈 채점 시, 사용자가 직접 작성한 정리 내용을 함께 참조하여 오답에 대해 "정리 노트에 없던 부분"인지 짚어주는 피드백을 제공한다.
12. 퀴즈는 스킵 가능해야 하며, 스킵해도 학습 완료 및 저장에는 영향이 없다.

## 7. 화면 구성 (레퍼런스 와이어프레임 기준)
1. **홈 (기사 입력)**: 기사 본문 붙여넣기 + 최근 학습 목록
2. **학습 화면 - AI 핵심 포인트 학습**: 포인트별 3단 설명 카드, N/M 진행 표시
3. **학습 화면 - 내 정리하기**: 자유 서술 입력창 + 키워드 힌트 칩
4. **마이페이지**: 누적 통계 카드 + 최근 학습한 뉴스 목록 (내 정리 보기 링크)
5. **[신규] 퀴즈 화면**: 학습 완료 후 선택적으로 진입, 문항별 객관식/OX + 정리 내용 기반 피드백

## 8. 차별성 (경쟁 서비스 대비)

| 기능 | 뉴닉/어피티 | 범용 요약 AI(NewsDigest 등) | 경제용어 퀴즈(생글생글 등) | 뉴스레슨 |
|---|---|---|---|---|
| 사용자가 원하는 기사 자유 입력 | ❌ (자체 콘텐츠만) | ✅ | ❌ | ✅ |
| 핵심 개념 선별(전체 아닌 1~3개) | ❌ | ❌ (전체 요약) | - | ✅ |
| 개념→맥락→영향 단계적 설명 | ❌ | ❌ | ❌ | ✅ |
| 확인 퀴즈 | ✅ (독립형) | ❌ | ✅ (독립형) | ✅ (정리 내용과 연결된 피드백) |
| 사용자가 직접 정리(산출) | ❌ | ❌ | ❌ | ✅ (핵심 차별점) |

**핵심 메시지**: 기존 서비스들은 요약 또는 퀴즈 중 한 기능에 머물러 있고, 이해 → 정리로 이어지는 학습 흐름은 제공하지 않는다. 퀴즈 역시 독립 기능이 아니라 사용자가 직접 작성한 정리와 연결된 피드백 루프로 차별화한다.

## 9. 완성도 우선순위 (MVP 스코프)

**필수 (Must-have)**
- 기사 붙여넣기 → 핵심 포인트 1~3개 선정 → 3단 설명 표시
- 사용자 정리 입력 → 저장
- 마이페이지 기본 목록/통계

**선택 (Nice-to-have, 시간 남으면)**
- 확인 퀴즈 + 정리 연동 피드백
- 키워드 힌트 칩 자동 생성
- 학습 완료 축하 화면: "정리하기" 완료 직후 전면 축하 연출 (연속 학습일 강조, SNS 공유 가능한 카드 이미지 생성 포함) — 학습을 라이트하고 습관적인 경험으로 만들기 위한 보너스 기능

## 10. 기술 스택 방향
- 프론트엔드: HTML/CSS/JS 또는 React (프레임워크 최소화)
- AI 처리: Claude API 호출 (핵심 포인트 선정 1회, 퀴즈 생성 시 1회 추가)
- 데이터 저장: 브라우저 메모리 또는 간단한 로컬 저장 (해커톤 데모 목적, DB 불필요)
- 출력 형식: JSON 구조로 강제하여 프론트 렌더링 안정성 확보

## 11. 발표 포인트
- "요약이 아니라 선별", "압축이 아니라 압축 해제"라는 프레이밍 유지
- 인출 학습(retrieval practice) 원리와 연결해 "직접 정리"의 학습 효과 근거 제시
- 퀴즈는 부가 기능이 아니라 "내 정리를 검증하는 장치"로 포지셔닝
