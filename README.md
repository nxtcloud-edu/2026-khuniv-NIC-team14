# 📰 뉴스레슨 (News Lesson)

경제 뉴스, 읽기는 하지만 이해는 안 되시나요?
**뉴스레슨**은 어려운 경제 기사를 붙여넣으면 AI가 꼭 알아야 할 핵심 개념만 골라 쉽게 설명해주고, 스스로 정리까지 이어지는 학습 서비스입니다.

---

## 💡 이런 문제에서 시작했어요

경제 뉴스에 등장하는 개념은 검색하면 뜻은 나옵니다.

하지만:
- 왜 이 기사에서 이 개념이 중요한지
- 이게 실제로 어떤 영향을 만드는지

여기까지 연결해서 이해하기는 쉽지 않고, 읽은 내용이 오래 남지도 않습니다.

**뉴스레슨은 요약이 아니라 "선별"합니다.
** 기사 전체를 압축하는 대신, 이해에 꼭 필요한 핵심 개념 1~3개만 골라 
**정의 → 쉬운 설명 → 기사 속 맥락 → 경제적 영향** 순서로 짚어주고, 마지막엔 직접 자신의 말로 정리하게 합니다.

## ✨ 주요 기능

- **기사 붙여넣기**: 읽고 싶은 경제 뉴스 본문을 그대로 입력
- **AI 핵심 포인트 선정**: Gemini API가 이해에 꼭 필요한 개념 1~3개를 자동 선별
- **4단 학습 카드**: 개념 정의 → 초등학생도 이해할 수 있는 쉬운 설명 → 기사 속 맥락 → 경제적 영향
- **내 말로 정리하기**: 학습을 마친 뒤 스스로 기사를 요약해보는 능동적 학습 단계
- **마이페이지**: 직접 정리한 뉴스 수, 이해한 핵심 포인트 수, 연속 학습일 등 누적 기록 확인
- **학습 완료 축하 화면**: 학습을 습관처럼 가볍게 만드는 보상 연출

## 🖥 화면 구성

| 화면 | 설명 |
|---|---|
| `index.html` | 홈 — 기사 붙여넣기, 최근 학습 목록 |
| `lesson.html` | AI 핵심 포인트 학습 (정의/쉬운설명/맥락/영향 4단 카드) |
| `summary.html` | 내 말로 정리하기 |
| `complete.html` | 학습 완료 축하 화면 |
| `mypage.html` | 마이페이지 — 누적 학습 통계, 지난 학습 기록 |

## 🛠 기술 스택

- **Frontend**: HTML / CSS / Vanilla JS (프레임워크 없이 경량 구현)
- **AI**: Google Gemini API (`gemini-3.6-flash`)
- **데이터 저장**: localStorage 기반 — 별도 서버/DB 없이 브라우저에 학습 기록을 영구 저장 (같은 브라우저 재방문 시에도 마이페이지 기록 유지)
- **개발 도구**: Claude Code

## 🚀 로컬에서 실행하기 (ver.01)

```bash
git clone https://github.com/nxtcloud-edu/2026-khuniv-NIC-team14.git
cd 2026-khuniv-NIC-team14

# API 키 설정
cp config.example.js config.js
# config.js를 열어 본인의 Gemini API 키를 입력하세요

# 브라우저로 열기
open index.html
```

> Gemini API 키는 [Google AI Studio](https://aistudio.google.com)에서 무료로 발급받을 수 있습니다.
